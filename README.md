# System design playground

Small interactive pages that go with Ankit Jain's System Design series (Hindi, YouTube).

| Episode | Playground |
|---|---|
| EP-1: HLD vs LLD, CAP, scaling | [Vertical vs horizontal scaling + CAP theorem](https://fardin98.github.io/system-design-playground/ep1/) |
| EP-4: Bloom vs Cuckoo vs Binary Fuse | [Filter playground](https://fardin98.github.io/filter-playground/) |

Each page is plain HTML + a small JS module, no build step. Self-test of the logic: `node ep1/selftest.mjs`.
