The HyperLogLog here is real: 16,384 six-bit registers (12 KB), the same size Redis uses; its typical error is about 0.81% (general). The exact set’s 8 bytes per id is a floor; real sets use more. Batch rules from the video: up to 50K events per batch, counters in Lua calls of 5K, Cuckoo adds in calls of 2K.
